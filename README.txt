POTTA FINANCE POS - README

Welcome to Potta Finance POS!

ABOUT POTTA FINANCE
Potta Finance is a comprehensive Point of Sale (POS) system designed for restaurants, cafes, and retail businesses. It provides powerful features for managing sales, inventory, customers, and business operations.

KEY FEATURES:
- Modern, intuitive user interface
- Real-time inventory management
- Customer relationship management
- Comprehensive reporting and analytics
- Multi-language support (English, French)
- Secure authentication system
- Restaurant operations (tables, orders, kitchen display)
- Expense tracking and cash management

SYSTEM REQUIREMENTS:
- Windows 10 or later (64-bit)
- .NET 8 Runtime (will be prompted to install if missing)
- Minimum 4GB RAM (8GB recommended)
- 500MB available disk space
- Internet connection for cloud features

GETTING STARTED:
1. Launch Potta Finance from your Start Menu or Desktop
2. Choose between Local or Organization login
3. Follow the setup wizard to configure your business
4. Start managing your business operations!
